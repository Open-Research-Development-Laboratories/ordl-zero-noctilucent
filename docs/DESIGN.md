# ORDL Zero Noctilucent

ORDL Zero Noctilucent | original palette by Maya Magikami (nlda lineage) for community from ORDL

An original, quiet instrument-panel aesthetic: blackened graphite, warm porcelain type, cool mist data colors and one aged-copper focus seam. The archive contributed the requirement for a coherent design thesis, intentional depth and restrained motion with accessibility. The live site contributed research-dossier structure, precision and quiet spacing. This is a new interpretation, not a palette extraction or a claim of globally unprecedented art.

## Spatial language
Optional standalone panel snippets use 1px outlines, 3px corners and clear inset spacing. The core palette does not set geometry. Aether/Omarchy native loaders decide which integration files apply. IBM Plex Mono is requested only in the optional notification/panel configs, with normal fallback; fonts are not bundled or installed.

## Motion
The wallpaper is static and the supplied configurations do not add continuous animation. This preserves legibility and avoids adding unmeasured compositor work. Source web animation concepts are not copied into desktop processes.

## Wallpaper
Original built-in image generation, visually inspected. Actual image is 1672 by 941 pixels. The prompt requested a wide 4K-like composition, but no 4K output or upscaling is claimed. The dark left area leaves space for work, with a porcelain/copper structure on the right.

## Roles
Copper identifies active focus. Cool opal identifies selection/data. Soft red, sage and sand retain meaningful error/success/warning distinctions. Bright ANSI slots are distinct from their normal partners. Gray comments are lifted for readability. Original Baked is untouched.
